Getting started

Installation

NezhaSim ships three ROS packages (nezha_description, nezha_gazebo, nezha_plugins), a vendored ROS Noetic port of the UUV Simulator and pinned Git submodules for the other upstream simulators.

ROS 1. NezhaSim targets ROS Noetic and Gazebo Classic, both end-of-life. rosdep therefore needs --include-eol-distros. A ROS 2 / PX4 version is planned.

1 · Install the prerequisites

# ROS Noetic (skip if installed)
sudo apt update
sudo apt install ros-noetic-desktop-full
# Build and dependency tools
sudo apt install python3-catkin-tools python3-rosdep python3-vcstool
sudo rosdep init

2 · Clone the workspace and its submodules

git clone --recurse-submodules \
  https://github.com/panzerjagerWang/NezhaSim-An-All-Domain-Simulator.git ~/nezha_ws
# already cloned without submodules?
cd ~/nezha_ws && git submodule update --init --recursive

src/nezha_sim/nezha.repos records the same upstream revisions for audits or for workspace layouts that use vcstool.

3 · Resolve dependencies and build

cd ~/nezha_ws
rosdep update --include-eol-distros
rosdep install --from-paths src --ignore-src -r -y --rosdistro noetic
catkin init
# the two hardware-in-the-loop packages are not needed for simulation
catkin config --skiplist rotors_hil_interface mavlink_sitl_gazebo
catkin build
source devel/setup.bash
Hardware in the loop. Remove mavlink_sitl_gazebo from the skiplist and install python3-jinja2 first. The PX4 HIL workflow is described in HITL_SETUP.md.

Add source ~/nezha_ws/devel/setup.bash to ~/.bashrc so new shells see the workspace.

4 · Verify

Gazebo opens with Nezha-Mini in the lake; the listings in a second sourced terminal confirm the plugins loaded.

roslaunch nezha_gazebo nezha_mini_lake.launch paused:=false
# in another sourced terminal
rostopic list | grep -E 'nezha_mini|drag'
rosservice list | grep -E 'hydrodynamics|phase'
Build failing? The usual causes are a submodule that was not initialized (repeat step 2) or a missing system dependency (repeat rosdep install).
